# **Sistema de Pontuação**

## **1\. Participação do Cidadão**

| Ação | Pontos |
| :---: | :---: |
| Relatar um problema fotos ou documentos úteis  | 50 |
| Relato validado  | \+50 |
| Avaliar o projeto após sua conclusão | \+20 |

## **2\. Líder de Comunidade**

| Ação | Pontos |
| :---: | :---: |
| Aceitar liderar um projeto | 100 |
| Entregar o plano de ação | 100 |

| Projeto aprovado pela Prefeitura | 200 |
| Projeto executado com sucesso | 100 |

## **5\. Ranking Trimestral**

Ao final de cada trimestre, os três projetos com maior pontuação receberão a premiação oficial da Prefeitura do Recife.

## **6\. Troca de Pontos**

Os pontos acumulados poderão ser utilizados para resgatar benefícios oferecidos pela Prefeitura do Recife.

| Recompensa | Pontos |
| :---: | :---: |
| Brindes institucionais | 500 |
| Ingressos para eventos | 800 |
| Vale-livros | 1.000 |
| Voucher em estabelecimentos parceiros | 1.500 |
| Cursos e capacitações | 2.000 |
| Benefícios especiais definidos pela PCR | Acima de 3.000 |
